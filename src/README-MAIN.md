
A classe Main.java é responsável por instanciar e interagir com a estrutura de dados da árvore binaria, voltada para a tradução de código Morse.

Ela faz o mapeamento automático das letras (A-Z) e números (0-9) para suas respectivas sequências em código Morse (`.` e `-`).
No momento de inicialização, ela exibe de forma hierárquica a eestrutura da árvore.
